# كروت المحتوى · Co & Part

بوابة داخلية لفريق Co & Part: بطاقات محتوى السوشال ميديا ولوحة أسابيع لكل عميل.

- الواجهة: صفحة ثابتة (`index.html`) على GitHub Pages، على العنوان `cards.saafprod.com`.
- البيانات وتسجيل الدخول: Supabase (مشروع `co-and-part-cards`). المفتاح الموجود في الصفحة مفتاح عام (publishable)، والوصول للبيانات محمي بسياسات Row Level Security: لا يقرأ أحد أي بيانات إلا إذا سجّل دخوله وكان بريده في جدول `members`.
- الصلاحيات: `editor` يضيف ويعدّل، و`viewer` يشاهد فقط.
